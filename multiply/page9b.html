🧮 Old-School Multiply Simulator — You Pick the Numbers!

Your turn to be the boss! Type ANY two numbers and press Go! — this simulator will write them out in columns and show the old-school workbook way to multiply them, step by step.

It follows the exact recipe from the Old-School Wizard: multiply by each digit of the bottom number (placing a 0 for each shift), then add the rows — and the simulator shows the addition too, column by column, so you see the whole thing exactly like in a real workbook!

🧠 Remember the old-school recipe?

1Line up the numbers — ones under ones. The longer number goes on top.
2Multiply the top number by each digit of the bottom number, starting with the ones.
3For the tens (then hundreds…) digit, write a 0 placeholder — that's the ×10 trick! Each new row shifts left one column.
4ADD all the rows — and you've got the answer! 🎉
